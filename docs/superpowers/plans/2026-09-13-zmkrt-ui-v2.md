# zmkrt ui v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the `zmkrt ui` page as a keyboard-first editor: keyboard fills the page, layers are chips, combos / encoder / hold-tap are edited on the board through a right-hand inspector; plus the two small firmware fields that make that possible.

**Architecture:** Firmware (module C + proto) gains `HoldTapInfo.behavior_id` and `ComboInfo.dt_binding`. The Python server passes them through, adds `effective` combo labels and a `?only=` partial fetch. The React app is restructured into Rail / TopBar / LayerChips / Keyboard (+ overlay + decor) / Inspector; the old panel tabs for hold-tap, combo and encoder disappear into the inspector.

**Tech Stack:** Zephyr/ZMK C (cormoran fork `v0.3-branch+dya`, nanopb), Python 3.12 stdlib server + protobuf 7.35.1, React 18 + TS + Tailwind 4 + Vite 6 + vitest 3.

**Spec:** `docs/superpowers/specs/2026-09-13-zmkrt-ui-v2-design.md` (this repo, `zmk-config-roBa`). Sub-project 1/2 specs in the same folder describe what exists today.

## Global Constraints

- Work in the module repo `zmk-module-runtime-config` (worktree given by `hw`). Everything below is relative to that repo unless it says `roBa repo`.
- Firmware cannot be compiled locally (no Zephyr toolchain). Firmware tasks must be *minimal, self-reviewed diffs*; the roBa CI (`zmk-config-roBa`, module pinned to `main`) is the compiler. Do not push the module's main until Task 3 (CLI) is green too, so a single push gives a buildable + usable state.
- Existing suites stay green at every commit: pytest (203 today) in `cli/` (`.venv/bin/pytest -q`), vitest (16 today) in `cli/ui` (`pnpm test`), `pnpm build` (tsc --noEmit + vite build) writes `cli/zmk_runtime_cli/ui/static/` which is committed.
- Both new proto fields are optional for the CLI: `behavior_id == 0` and a missing `dt_binding` mean "unknown" (old firmware).
- Copy is Japanese: 適用 / 既定に戻す / 再読込 / スナップショット / リセット / 変更履歴 / コンボ表示.
- Never call `POST /api/reset` against the real device. The user's viewing server may be running on port 8760 with the main checkout; before any HIL, `pgrep -fl "zmkrt ui"` and kill only that process, and restart it (`cd <main checkout>/cli && nohup .venv/bin/zmkrt ui --http-port 8760 --no-open &`) when done.

```c
int rt_combo_dt_binding(uint8_t index, struct rt_combo_params *out) {
    if (index >= ARRAY_SIZE(combos) || out == NULL) {
        return -EINVAL;
    }
    const struct zmk_behavior_binding *b = &combos[index].behavior;
    zmk_behavior_local_id_t id = zmk_behavior_get_local_id(b->behavior_dev);
    if (id == UINT16_MAX) {
        return -ENODEV;
    }
    *out = (struct rt_combo_params){
        .behavior_local_id = id,
        .param1 = b->param1,
        .param2 = b->param2,
    };
    return 0;
}
```

        entries = []
        for r in session.combos_client().list():
            info = r["info"]
            b = info["binding"]

import type { KeyBox } from "./geometry";
import type { ComboEntry, Encoder, EncoderLayer, HoldtapSlot } from "./types";

/** Centre of a cap after its rotation (matches the SVG `rotate(deg cx cy)`). */
export function keyCenter(b: KeyBox): [number, number] {
  const px = b.x + b.w / 2;
  const py = b.y + b.h / 2;
  const a = (b.deg * Math.PI) / 180;
  const dx = px - b.cx;
  const dy = py - b.cy;
  return [b.cx + dx * Math.cos(a) - dy * Math.sin(a), b.cy + dx * Math.sin(a) + dy * Math.cos(a)];
}

export function comboPath(entry: ComboEntry, boxes: KeyBox[]) {
  const byPos = new Map(boxes.map((b) => [b.pos, b]));
  const points = entry.key_positions
    .map((p) => byPos.get(p))
    .filter((b): b is KeyBox => !!b)
    .map(keyCenter);
  const n = points.length || 1;
  const centroid: [number, number] = [
    points.reduce((s, [x]) => s + x, 0) / n,
    points.reduce((s, [, y]) => s + y, 0) / n,
  ];
  return { points, centroid };
}

/** Combos that fire on `layerIndex`: no layer filter, or the filter names it. */
export function activeCombos(entries: ComboEntry[], layerIndex: number): ComboEntry[] {
  return entries.filter((e) => e.layers.length === 0 || e.layers.includes(layerIndex));
}

/** The runtime hold-tap slot owned by `behaviorId` (0 = unknown, never matches). */
export function holdtapSlotFor(slots: HoldtapSlot[], behaviorId: number): HoldtapSlot | undefined {
  if (behaviorId === 0) return undefined;
  return slots.find((s) => s.behavior_id === behaviorId);
}

export function encoderLayerBinding(
  encoder: Encoder,
  sensor: number,
  layerIndex: number,
): EncoderLayer | undefined {
  if (!encoder.available) return undefined;
  return encoder.bindings.find((b) => b.sensor === sensor)?.layers.find((l) => l.layer === layerIndex);
}
